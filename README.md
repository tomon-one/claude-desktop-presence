# claude-desktop-presence

Код проекта написан Claude, ИИ от Anthropic. Подробнее об этом [в конце](#как-написан-код).

[English](README.en.md)

Карточка Discord для Claude Desktop на Linux. Показывает, какой чат открыт и чем Claude сейчас занят. Вместо скучного «думает» в ней пасхалки из песен, игр и сериалов.

![Карточка в профиле Discord](docs/card.png)

- **Первая строка:** название открытого чата. Если чат не выбран, пишет «Главное меню».
- **Вторая строка:** что делает Claude. Думает, правит файлы, задал вопрос с вариантами, ждёт разрешения на команду, только что ответил, ждёт, упёрся в ошибку или сжимает контекст. Для каждого состояния есть свой набор фраз.
- **Время:** сколько открыт Claude Desktop. При смене чата не сбрасывается.

Это один файл на Python без зависимостей. С Discord он общается напрямую через локальный сокет.

## Установка

Нужны Linux с systemd, Python 3.11 или новее, Claude Desktop и Discord. Подойдёт обычный Discord, Flatpak, Snap или Vesktop.

1. Создай приложение на [discord.com/developers/applications](https://discord.com/developers/applications). Его имя Discord покажет после «Играет в». Имя «Claude» занято, подойдёт, например, «ClaudeDesktop».
2. В разделе Rich Presence → Art Assets загрузи картинку 1024×1024 с ключом `claude`. Скопируй Application ID со страницы General Information.
3. Установи:
   ```bash
   git clone https://github.com/tomon-one/claude-desktop-presence
   cd claude-desktop-presence
   ./install.sh
   ```
4. Впиши Application ID в `~/.config/claude-desktop-presence/config.toml` и запусти службу:
   ```bash
   systemctl --user enable --now claude-desktop-presence
   ```

Если Discord сам нашёл процесс `claude` и показывает пустую карточку, удали его в настройках Discord, раздел «Зарегистрированные игры».

`install.sh` добавляет в `~/.claude/settings.json` хук `PreCompact`. Пока Claude сжимает контекст, он ничего не пишет в журнал сессии, и без хука это состояние не увидеть. Хук только оставляет пустой файл-метку в `~/.cache/claude-desktop-presence/`. Старая версия настроек сохраняется в `settings.json.bak`. Установить без хука: `./install.sh --no-hook`.

## Настройка

Всё лежит в `~/.config/claude-desktop-presence/`:

| файл | что в нём |
|---|---|
| `config.toml` | Application ID, картинка, подписи для особых случаев, что показывать в списке участников сервера |
| `words.txt` | фразы и пасхалки, перечитываются на лету |
| `hide.txt` | части названий чатов, которые надо скрыть |

В `config.toml` есть и необязательное:

- `status_display = "state"`: в списке участников сервера под ником будет фраза, а не имя приложения.
- `state_icons = true`: маленький значок состояния в углу картинки. Готовые значки лежат в [docs/icons](docs/icons), их надо загрузить в Art Assets с ключами по именам файлов.
- `buttons`: до двух кнопок со ссылками. Себе Discord их не показывает, их видят другие.

После правки `config.toml` перезапусти службу: `systemctl --user restart claude-desktop-presence`. Лог: `journalctl --user -u claude-desktop-presence -f`.

## Пасхалки

Фразы лежат в `words.txt` по разделам, по одной в строке. Условие пишется после `@`, например `Wake up, Samurai @дольше 30`. Фраза меняется раз в 30 секунд и при каждой смене состояния.

| условие | когда показывается |
|---|---|
| без условия | всегда, вперемешку с остальными |
| `@ночь` | с 23:00 до 5:00, вперемешку с остальными |
| `@03:45` | только в эту минуту, вместо остальных |
| `@дольше 30` | состояние длится больше 30 минут. Чередуется с обычными фразами, из нескольких порогов берётся больший |
| `@утро` | первое ожидание за утро, с 5 до 12. Чередуется с обычными фразами |
| `@шанс 25` | с вероятностью 25 % при входе в состояние. Чередуется с обычными фразами |
| `@запуск` | только в разделе `[событие]`: первая минута после запуска Claude Desktop |
| `@переключение 15` | только в разделе `[событие]`: с вероятностью 15 % при смене чата, на минуту |

## Приватность

Карточку видят все, кому Discord показывает твою активность, то есть друзья и участники общих серверов. Значит, им видны и названия чатов. Скрыть отдельные чаты можно через `hide.txt`. Отключить активность для конкретного сервера можно в настройках Discord, раздел «Конфиденциальность активности». В лог службы попадают только состояния, названия чатов туда не пишутся.

## Как это работает

- **Открытый чат.** Claude Desktop пишет в `~/.config/Claude/logs/main.log` строку `setFocusedSession` при каждом переключении. Если там `null` дольше 5 секунд, чат не выбран. Названия берутся из `~/.config/Claude/claude-code-sessions/`.
- **Состояние.** Скрипт читает конец журнала сессии `~/.claude/projects/*/<id>.jsonl`. Ответ закончен: ждёт. Последний инструмент `Edit` или `Write`: правит файлы. `AskUserQuestion`: вопрос с вариантами. Ошибка API: ошибка. Иначе думает. Уведомления о фоновых задачах и локальные команды новым ходом не считаются. Ожидание разрешения и долгие команды видны по служебному файлу Claude Code `~/.claude/sessions/<pid>.json`, где записано, занята сессия или чего-то ждёт.
- **Discord.** Карточка уходит командой `SET_ACTIVITY` через `$XDG_RUNTIME_DIR/discord-ipc-N`. Опрос раз в 4 секунды, отправка только при изменениях. Если Discord закрыт, пауза между попытками растёт до минуты.

Claude Desktop и Claude Code не обещают сохранять эти файлы в прежнем виде, и обновление может что-то сломать. Если карточка ведёт себя странно, сначала загляни в лог службы.

## Обновление и удаление

```bash
git pull && ./install.sh
```

Свой `words.txt` установщик не перезаписывает. Новые фразы можно посмотреть командой `diff words/ru.txt ~/.config/claude-desktop-presence/words.txt`.

Удаление: `./install.sh --uninstall`. Оно убирает службу, скрипт и хук, а настройки оставляет.

## Разработка

```bash
python3 -m unittest discover -s tests -v
```

Проверки работают на искусственных журналах и поддельном сокете Discord. Настоящие Claude Desktop и Discord для них не нужны.

## Как написан код

Весь код, проверки и этот README написал Claude в Claude Code. Проект вырос из одного разговора о настройке системы: сначала был скрипт на сотню с небольшим строк, потом пасхалки, потом отдельный репозиторий.

Человек придумывал, что и когда показывать, сочинял пасхалки, проверял всё на своём Discord и решал, что оставить. Claude писал код, искал причины багов по логам и журналам, сверялся с документацией Discord и чужими проектами. Перед публикацией Claude провёл аудит: несколько независимых агентов искали баги, а отдельный агент пытался опровергнуть каждую находку. Проверки дополнительно прогнали на нарочно сломанном коде, чтобы убедиться, что они действительно ловят ошибки.
