# claude-desktop-presence

**Карточка Discord для Claude Desktop на Linux.** Показывает, какой чат открыт и чем Claude занят, а вместо скучного «думает» пишет пасхалки из песен, игр и книг.

## Зачем это

Discord и сам замечает процесс `claude`, но рисует пустую карточку с вопросительным знаком. Эта программа заменяет её на живую:

- **первая строка:** название открытого чата, а если чат не выбран, «Главное меню»;
- **вторая строка:** что делает Claude. Думает, правит файлы, задал вопрос, ждёт разрешения, только что ответил, ждёт тебя, упёрся в ошибку или сжимает контекст. У каждого состояния свой набор фраз, и большая часть из них пасхалки;
- **время:** сколько открыт Claude Desktop, при смене чата не сбрасывается.

Программа решает одну задачу. Модели, токенов, лимитов и статистики здесь нет специально. Если нужны они, посмотри [rar-file/claude-rpc](https://github.com/rar-file/claude-rpc) или [BrunoJurkovic/claude-code-discord-status](https://github.com/BrunoJurkovic/claude-code-discord-status): они показывают больше, но работают с Claude Code, а не с Desktop.

**Что это технически.** Один файл на Python без сторонних библиотек и служба systemd. С Discord он общается напрямую через локальный сокет, в интернет не ходит. Читает только файлы Claude на диске, ничего в них не пишет.

## Чего не умеет

Стоит знать до установки.

- **Работает только с Claude Desktop.** Открытый чат он узнаёт из лога Desktop. Сессии Claude Code в обычном терминале карточку не меняют.
- **Облачные сессии без состояния.** Если открыт облачный чат, карточка пишет «Облачная сессия» и фразы из раздела «чат не выбран»: журнала облачной сессии на диске нет.
- **Сжатие контекста видно только с хуком.** Пока Claude сжимает контекст, он ничего не пишет в журнал. Установщик добавляет для этого хук `PreCompact` в `~/.claude/settings.json`. Без хука состояние «сжимает» не появится.
- **Ожидание разрешения на живом запросе не проверено.** Состояние берётся из служебного файла Claude Code, значение нашлось в его коде, но настоящий запрос разрешения программа пока не видела.
- **Названия чатов видят другие.** Подробнее в [Приватность](#приватность).

## Установка

1. Создай приложение на [discord.com/developers/applications](https://discord.com/developers/applications). Его имя Discord покажет после «Играет в». Имя «Claude» занято, подойдёт, например, «ClaudeDesktop».
2. В разделе Rich Presence → Art Assets загрузи картинку 1024×1024 с ключом `claude`. Скопируй Application ID со страницы General Information.
3. Установи:
   ```bash
   git clone https://github.com/tomon-one/claude-desktop-presence
   cd claude-desktop-presence
   ./install.sh
   ```
4. Впиши Application ID в `~/.config/claude-desktop-presence/config.toml` и запусти службу:
   ```bash
   systemctl --user enable --now claude-desktop-presence
   ```
5. Если Discord сам нашёл процесс `claude` и показывает пустую карточку, удали его в настройках Discord, раздел «Зарегистрированные игры».

Хук `PreCompact` установщик добавляет в `~/.claude/settings.json`, прежняя версия файла остаётся в `settings.json.bak`. Хук только оставляет пустой файл-метку в `~/.cache/claude-desktop-presence/`. Установить без него: `./install.sh --no-hook`. Слова и подписи по-английски: `./install.sh --lang en`.

## Настройка

Всё лежит в `~/.config/claude-desktop-presence/`:

| файл | что в нём |
|---|---|
| `config.toml` | Application ID, картинка, подписи для особых случаев и необязательные настройки ниже |
| `words.txt` | фразы и пасхалки, перечитываются на лету |
| `hide.txt` | части названий чатов, которые надо скрыть |

Необязательное в `config.toml`:

| настройка | что делает |
|---|---|
| `status_display = "state"` | в списке участников сервера под ником будет фраза, а не имя приложения |
| `state_icons = true` | маленький значок состояния в углу картинки. Готовые значки лежат в [docs/icons](docs/icons), загрузи их в Art Assets с ключами по именам файлов |
| `buttons` | до двух кнопок со ссылками. Себе Discord их не показывает, их видят другие |

После правки `config.toml` перезапусти службу: `systemctl --user restart claude-desktop-presence`. Лог: `journalctl --user -u claude-desktop-presence -f`.

## Пасхалки

Фразы лежат в `words.txt` по разделам, по одной в строке. Условие пишется после `@`, например `Wake up, Samurai @дольше 30`. Фраза меняется раз в 30 секунд и при каждой смене состояния.

| условие | когда показывается |
|---|---|
| без условия | всегда, вперемешку с остальными |
| `@ночь` | с 23:00 до 5:00, вперемешку с остальными |
| `@03:45` | только в эту минуту, вместо остальных |
| `@дольше 30` | состояние длится больше 30 минут. Чередуется с обычными фразами, из нескольких порогов берётся больший |
| `@утро` | первое ожидание за утро, с 5 до 12. Чередуется с обычными фразами |
| `@шанс 25` | с вероятностью 25 % при входе в состояние. Чередуется с обычными фразами |
| `@запуск` | только в разделе `[событие]`: первая минута после запуска Claude Desktop |
| `@переключение 15` | только в разделе `[событие]`: с вероятностью 15 % при смене чата, на минуту |

## Приватность

Карточку видят все, кому Discord показывает твою активность, то есть друзья и участники общих серверов. Значит, им видны и названия чатов. Скрыть отдельные чаты можно через `hide.txt`. Отключить активность для конкретного сервера можно в настройках Discord, раздел «Конфиденциальность активности». В лог службы попадают только состояния, названия чатов туда не пишутся.

## Как устроено

- **Открытый чат.** Claude Desktop пишет в `~/.config/Claude/logs/main.log` строку `setFocusedSession` при каждом переключении. Если там `null` дольше 5 секунд, чат не выбран. Названия берутся из `~/.config/Claude/claude-code-sessions/`.
- **Состояние.** Скрипт читает конец журнала сессии `~/.claude/projects/*/<id>.jsonl`. Ответ закончен: ждёт. Последний инструмент `Edit` или `Write`: правит файлы. `AskUserQuestion`: вопрос с вариантами. Ошибка API: ошибка. Иначе думает. Уведомления о фоновых задачах и локальные команды новым ходом не считаются.
- **Разрешения и долгие команды.** Claude Code держит для каждой сессии файл `~/.claude/sessions/<pid>.json`, где записано, занята она или чего-то ждёт. Скрипт верит только файлам живых процессов: имя и время запуска процесса должны совпасть.
- **Discord.** Карточка уходит командой `SET_ACTIVITY` через `$XDG_RUNTIME_DIR/discord-ipc-N`. Опрос раз в 4 секунды, отправка только при изменениях. Если Discord закрыт, пауза между попытками растёт до минуты.

Если карточка ведёт себя странно, сначала загляни в лог службы.

## Обновление и удаление

```bash
git pull && ./install.sh
```

Свой `words.txt` установщик не перезаписывает. Новые фразы можно посмотреть командой `diff words/ru.txt ~/.config/claude-desktop-presence/words.txt`.

Удаление: `./install.sh --uninstall`. Оно убирает службу, скрипт и хук, а настройки оставляет.

Проверки: `python3 -m unittest discover -s tests -v`. Они работают на искусственных журналах и поддельном сокете Discord, настоящие Claude Desktop и Discord им не нужны.

## Написано вместе с ИИ

Весь код, проверки и этот README написал Claude в Claude Code. Человек придумывал, что и когда показывать, сочинял пасхалки, проверял всё на своём Discord и решал, что оставить. Само по себе «написано ИИ» ничего не доказывает, поэтому вот чем проверенное отличали от просто сгенерированного.

**Ошибки, которые нашлись только в живой работе.** Карточка мигала: проверка «жив ли Discord» ждала ответа 5 секунд, считала тишину обрывом и рвала соединение каждый опрос. После исчерпанного лимита карточка показывала «думает»: уведомление о фоновой задаче попадает в журнал как сообщение пользователя. Сжатие контекста не было видно вовсе: оказалось, что во время сжатия Claude ничего не пишет в журнал, отсюда хук. Все три заметил человек, глядя на свой профиль, а не проверка кода.

**Аудит независимыми агентами.** Перед публикацией пять агентов, у каждого своя тема, прошли проект: похожие проекты и их приёмы, сверка с документацией Discord, ошибки и поведение при отказах, лишний код и комментарии, расхождения README с кодом. Ещё один агент с обратной задачей пытался опровергнуть каждую найденную ошибку. Из 43 находок он подтвердил 41, в основном мелкие. Всё подтверждённое исправлено.

**Проверки, которые сами проверены.** 41 автоматическая проверка: искусственные журналы сессий, лог Desktop, файл слов, поддельный сокет Discord. Ключевые проверки прогнали на нарочно сломанном коде: убирали исправление и смотрели, что проверка падает. Установщик отдельно прогнали в песочнице с подставным домашним каталогом.

**Чего это не значит.** Программа видела один компьютер, одну сборку Claude Desktop и обычный Discord. Пути Flatpak, Snap и Vesktop только написаны. Ожидание разрешения на живом запросе не проверялось.
